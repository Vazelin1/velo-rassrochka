# Версия 28. Штраф, неустойка и сроки доплаты

Сроки считаются в календарных днях по Москве. Дата платежа по графику — последний день плановой оплаты.

| Если платёж по графику 20-го | Срок без начислений | Дальше |
| --- | --- | --- |
| Ничего не внесено | 21-е и 22-е включительно | 23-го начисляется разовый штраф 350 ₽. С 24-го идёт ежедневная неустойка по ставке договора. |
| Половина внесена 22-го | Остаток можно внести до конца 24-го | С 25-го неустойка начисляется только на остаток. На остаток штрафа нет. |

Для каждой частичной оплаты срок доплаты ограничен четырьмя календарными днями после даты взноса. Штраф и неустойка, возникшие к моменту первой оплаты, входят в неё. Следующие начисления идут на остаток со дня, следующего за первым платежом, если срок доплаты к тому моменту истёк.

Клиент и администратор работают по датам графика. Ранее согласованные даты и уже записанные сроки доплаты сохранены. В кабинете правила доступны в «Памятке по кабинету», а при оплате частями приложение показывает точную дату доплаты. В «Отчётах» → «Получено за период» строка «Штрафы и неустойки» показывает сумму фактически оплаченных начислений, а ниже указан каждый вид начислений. Эти поступления входят в общий доход один раз.

В окне оплаты по СБП нажмите «Оплатить в своём банке» и выберите банк. Для загрузки QR-кода в банк используйте «Скачать QR-код» → «Скачать PNG». На iPhone можно нажать «Открыть изображение», сохранить QR в «Фото» и выбрать его в онлайн-банке, если там поддерживается оплата QR из галереи.

Для установки поверх версии 27 сохраните резервную копию и замените файлы из архива в папке выкупа с сохранением вложенности. Пересоберите приложение из этой папки.

```bash
docker compose up -d --build app
```

# Версия 21. Тарифы, оплата пополам и расходы

Новые договоры аренды с правом выкупа доступны на 20 и 26 недель. Эти же сроки используются в настройках тарифов и клиентском калькуляторе. В действующих и архивных договорах сохранены сроки, суммы по графику и история оплат.

## Настройка и выдача

1. Откройте «Настройки» → «Бренды, модели и АКБ». Добавьте бренд и модель или откройте существующую модель и нажмите «Изменить модель». Укажите закупку велосипеда без АКБ. Модели из прежней версии можно назначить нужному бренду из группы «Без бренда». В базе велосипеды сгруппированы по брендам.
2. В карточке модели добавьте нужные варианты аккумуляторов. Для каждого укажите напряжение, ёмкость и закупочную цену. Метку можно заполнить, чтобы отличать варианты с одинаковыми параметрами. Откройте «Тарифы аренды с правом выкупа» для настройки комплекта.
3. Нажимайте «Добавить АКБ», чтобы собрать комплект из вариантов выбранной модели. Нажатие на выбранный АКБ меняет вариант, а «×» убирает аккумулятор из комплекта. Сумма закупки считается по выбранным позициям. Для велосипеда, купленного в сборе, можно задать закупку готовой комплектации в тарифе. Выберите срок и введите недельную плату или итоговую цену выкупа. Второе поле пересчитается сразу. Остаток от округления сохраняется в доплате за выкуп.
4. Укажите обеспечительный платёж и сохраните тариф. В прогнозе видны закупка, выручка, комиссии, налог, прибыль и остаток к выкупу. Предполагается оплата по СБП. Фактическую закупку конкретного велосипеда можно указать в его карточке. Она используется в учёте сделки, если заполнена.
5. В меню «Добавить» выберите «Аренду с правом выкупа». Выберите клиента, велосипед, фактическую комплектацию АКБ и тариф. Отметьте, что получили первую неделю и обеспечение, затем сохраните. Условия и комплектация фиксируются при выдаче.

Кнопка «Расчёт для клиента» на главной показывает сохранённые тарифы выбранной комплектации. Из калькулятора можно скопировать предложение и скачать таблицу или график в PNG. Инструкция по оплате, графику и выкупу расположена в клиентском кабинете под кнопками связи.

## Оплаты, выкуп и возврат

- В кабинете клиента нажмите «Оплатить период», чтобы оплатить от одного до четырёх ближайших периодов одним QR. Суммы за выбранные периоды складываются. Ранее начисленные скидки остаются в истории и в графике.
- При выборе «Оплатить 50% ближайшего периода» приложение показывает первую сумму, остаток и крайний день доплаты включительно. Оставшиеся 50% вносятся одним платежом. Срок доплаты и порядок начисления описаны в разделе «Версия 28».
- Шкала в кабинете показывает оплату первых четырёх периодов и сколько осталось до открытия выкупа. Выкуп доступен с начала пятой недели после полной оплаты первых четырёх недель. Когда оба условия выполнены, клиент видит сумму финального платежа. В цену выкупа засчитывается арендная плата в пределах полной цены. Обеспечение и неустойка учитываются отдельно. Выкуп оформляется отдельным действием, даже когда доплата равна нулю.
- Срок аренды задаётся при выдаче. Для продления после согласования с клиентом откройте карточку → «Действия» → «Договор» → «Продлить аренду». Приложение использует ту же недельную ставку и показывает общую дату окончания.
- После полной оплаты клиент видит приглашение согласовать встречу. В карточке владельца рядом с «Позвонить» появляется «Закрыть выкуп». Для аренды с правом выкупа в этом окне доступен печатный HTML-акт с ценой, зачтённой арендой, доплатой и данными об обеспечении. Заполните реквизиты арендодателя, дату перехода права собственности по договору и подпишите акт. Перед отправкой сделки в архив подтвердите подпись документов, снятие маячка, передачу второго комплекта ключей и документов на велосипед. Четыре отметки сохраняются в карточке сделки.
- При возврате велосипеда приложение рассчитывает возврат платы за оставшиеся дни после даты фактического возврата. Закрытие аренды записывает возврат после вашей отметки о перечислении. Возврат или удержание обеспечительного платежа учитывается отдельно через «Отметить возврат обеспечения» в действиях договора и в отчётах.
- Суммы выкупа в отчёте учитывают только фактические поступления. Акт описывает расчёт между сторонами. Фискализация по-прежнему относится к вашей кассе, а запись в приложении служит для учёта.

## Отчёты и аналитика

- «Платежи по графику» объединяют регулярные взносы и оплату аренды. Доплаты за выкуп показаны отдельно.
- В «Отчётах» раскройте «Расходы» и нажмите «Добавить расход». Укажите дату, описание и сумму. Владелец может изменить или удалить запись. Разовый расход уменьшает прибыль за соответствующий период и включается в резервную копию.
- В помесячной таблице «В выкупе» — остаток договоров в процессе на конец месяца. Для текущего месяца берётся сегодняшняя дата. «Выплачено» учитывается по дате полного расчёта.
- «Когда клиенты выкупают велосипед» показывает срок от выдачи до фактической доплаты по договорам аренды за выбранный год. По каждому диапазону недель показаны количество выкупов, доля среди выкупов с доплатой и средняя доплата за велосипед. Выкупы без доплаты показаны отдельно.

Перед заменой файлов сохраните резервную копию. После замены файлов из архива перезапустите контейнер из папки приложения.

```bash
docker compose up -d --build
```

# Тарифы и клиентский калькулятор выкупа

В «Настройки» → «Тарифы выкупа» выберите модель и количество аккумуляторов. Для каждой комплектации можно задать недельный платёж на 8, 12, 16, 20 и 26 недель. Сохранённые тарифы используются в клиентском предложении и при оформлении выкупа. После обновления прежние тарифы «Монстра» и U2 доступны в комплектациях с 1 АКБ.

В «Настройки» → «Первоначальный взнос» для 10 000, 20 000, 30 000, 40 000 и 50 000 ₽ задаются скидки в рублях. Значение 0 ₽ означает, что скидки за этот взнос нет. Настройка действует на все модели и сроки. Скидка вычитается из полной цены, затем из суммы к оплате вычитается первоначальный взнос. Полная цена по тарифу округляется до рубля, еженедельные платежи определяются в целых рублях, остаток от деления включается в последний платёж. Если взнос покрывает цену целиком, график пуст.

Перед выдачей проверьте модель, количество аккумуляторов и фактическую закупочную цену в карточке велосипеда. В карточках без количества приложение подставляет 1 АКБ. При оформлении сохраняются условия тарифа, скидка по выбранному взносу, закупочная цена велосипеда и сумма, полученная при выдаче. При наличии графика она включает первоначальный взнос и первый платёж. Новые настройки применяются к следующим предложениям и сделкам.

На главной нажмите «Расчёт для клиента» и выберите комплектацию и первоначальный взнос. Таблица покажет скидку, еженедельный платёж, полную цену и сумму при выдаче. Общая памятка объясняет, как увеличенный первоначальный взнос влияет на остаток и полную цену, а также когда доступен досрочный выкуп. Суммы по выбранным срокам указаны в таблице и графике. Кнопка «Скачать картинку» сохраняет таблицу или график с этой памяткой в PNG.

В «Настройки» → «Тарифы выкупа» выберите комплектацию и первоначальный взнос для расчёта. Для U2 подставляется закупка 59 000 ₽ с 1 АКБ и 85 000 ₽ с 2 АКБ. Выручка после скидки, расходы, прибыль и процент от закупки обновляются сразу. Прогноз использует текущие ставки и предполагает оплату по СБП. Кнопка «Сохранить тарифы и закупку» применяет цены к клиентскому расчёту и новым выкупам.

В форме «Новый выкуп» можно вписать подарок клиенту и его себестоимость. Подарок учитывается в расходах на дату выдачи, в окупаемости велосипеда и в итогах сделки. После полной оплаты в карточке открываются «Итоги выкупа», которые также доступны в архиве. Итоги учитывают фактические платежи, возвраты и неустойки, закупку, дополнительное оборудование, подарки, расчётный налог и комиссии. Расходы на обслуживание относятся к общим отчётам по парку. Наличные входят в выручку и расчёт налога. Комиссии эквайринга и сервиса чеков относятся к оплатам по СБП.

# Досрочный выкуп

При оформлении приложение фиксирует более выгодные короткие тарифы той же комплектации. Для каждого срока учитывается согласованная скидка за первоначальный взнос. Крайние даты считаются от даты выдачи. Между концами недель цена меняется по дням с округлением до рубля для новых выкупов. Для действующего договора владелец может открыть «Действия» → «Договор» → «Подключить досрочный выкуп» и подтвердить цены по текущим тарифам.

Кнопка досрочного выкупа в кабинете появляется после полной оплаты первых четырёх периодов, пока есть экономия к текущему графику. Оплата первого периода при выдаче засчитывается. Первоначальный взнос входит в стоимость велосипеда. Если в одном из первых четырёх периодов есть долг, кнопка появится после его погашения.

В расчёте клиент видит цену на дату полного расчёта, уже зачтённые платежи, экономию к текущему графику и оставшуюся доплату. Ранее предоставленная скидка учитывается в текущем графике. Досрочный расчёт уменьшает стоимость до цены на выбранную дату, если она ниже. Начисленная неустойка входит в доплату отдельной строкой. Если платежи уже покрывают цену, остаётся подтвердить полный выкуп или внести начисленную неустойку.

Клиент получает QR по актуальной сумме. Владелец может учесть фактически принятые деньги в карточке через «Действия» → «Оплата» → «Досрочный выкуп». После подтверждения оплаты график закрывается. В истории и отчётах поступление отражается в дату полного расчёта. После подписания документов завершите и отправьте выкуп в архив обычной кнопкой.

На вкладке «Аналитика» нажмите «Выгодные сроки», чтобы раскрыть статистику прибыли.

В разделе «Настройки» → «Журнал действий» отображаются последние 250 событий. Поиск работает по действию, карточке, автору и дате. Используйте фильтр по разделу и нажмите на событие, чтобы увидеть дату и время по Москве, автора и изменённые значения в столбцах «Было» и «Стало». Подробности старых записей зависят от данных, сохранённых в момент действия.

# Обновление оплаты и графика выкупа

В «Выбрать оплату» клиент указывает количество ближайших неоплаченных периодов или часть ближайшего платежа. При оплате двух и более периодов одним платежом начисляется скидка. Ставка задаётся в настройках, начальное значение 1,5%. Например, за 15 000 ₽ начисляется 225 ₽ сверх внесённых денег. Скидка уменьшает платежи с конца графика. Если она достигает выбранного последнего периода, уменьшается сумма к оплате. Неустойка оплачивается отдельно. Описание и расчёт доступны клиенту до оплаты через кнопку «?».

Частичная оплата начинается от 50% периода. Минимум можно увеличить в настройках. Неустойка за прошедшие дни оплачивается целиком. Остаток вносится до конца четвёртого дня после срока взноса, затем на него начисляется ежедневная неустойка. При открытом долге доступны полные платежи за следующие периоды.

В карточке выкупа нажмите «Показать весь график», затем «Перенести период» у оплаты. Перед подтверждением виден расчёт с учётом суммы целевого периода и неустойки на дату получения денег. Доплаты долга переносятся вместе с исходной оплатой, даты и способы получения денег учитываются в истории. Переплата уменьшает последние платежи. Отмена общей оплаты нескольких периодов отменяет всю эту оплату и её скидку.

Клиент может изменить график один раз за выкуп после одобрения заявки. Дата первого пересчитываемого взноса может отличаться от его даты в действующем графике на 7 дней в любую сторону. В «Действиях» карточки выкупа есть отдельное ручное изменение графика для владельца и администратора с правом «Выкупы». Дату последнего взноса берём из действующего графика. До отправки заявки клиент видит обе последние даты, интервал между ними и таблицу «Было → Стало» с датами и суммами. Короткий интервал выделяется в расчёте. Если до даты окончания помещается меньше взносов, остаток после регулярных взносов приходится на последний платёж, и его сумма видна в расчёте.

Заявка появляется на главной и в карточке выкупа. Нажмите «Рассчитать», проверьте суммы и даты, затем одобрите или отклоните заявку. В перерасчёт входит будущий остаток с учётом оплат и скидок. Просроченные периоды и долг оплачиваются по своим срокам. После новой оплаты потребуется пересчитать график перед одобрением. Предыдущие графики записываются в историю выкупа.

После полной оплаты клиент видит приглашение приехать для подписания документов и получения второго комплекта ключей. Бот тоже отправит приглашение, если включены уведомления клиентам. На главной у владельца выкуп появится в блоке «Ждут подписания документов». После приезда клиента нажмите «Закрыть выкуп» и заполните чек-лист передачи. В архив включаются платежи, скидки, история графиков, дата подписания и фотографии велосипеда.

На главной есть сворачиваемый блок «План и факт по дням» с переключением недель. В аналитике добавлена сезонность выдач, полных выплат и возвратов по месяцам. Полная выплата учитывается по дате последнего взноса, возврат — по закрытию с изъятием велосипеда.

Комиссия за формирование чеков задаётся в настройках отдельным процентом, начальное значение 0%. В отчётах она считается с фактически полученных платежей по СБП и учитывается в прибыли. При оформлении прогноз использует выбранный способ оплаты при выдаче. Для последующих платежей он предполагает СБП. Ставки эквайринга и чеков фиксируются при учёте оплаты. Старые платежи без сохранённой ставки при обновлении получают текущие ставки и пометку «оценка».

Кнопка «QR для входа» есть в карточке клиента и выкупа. Покажите код клиенту при выдаче. Он открывает свой кабинет в Telegram без ввода телефона. Код действует 10 минут и используется один раз.

Для установки обновите `server.py`, `static/calc.js`, `static/index.html` и этот `README.md` в репозитории, затем выполните команды обновления из раздела ниже.

# Установка (Selectel + Telegram)
1. Telegram: в @BotFather команда /newbot, сохраните токен. Ваш числовой ID узнайте у @userinfobot.
2. Selectel: создайте облачный сервер Ubuntu 24.04 (1 vCPU, 1-2 ГБ), запишите его IP. У регистратора домена создайте запись A: ваш (под)домен -> IP сервера.
3. Подключитесь: `ssh root@IP`. Установите Docker: `curl -fsSL https://get.docker.com | sh`
4. Загрузите папку проекта на сервер (с вашего компьютера: `scp -r velo root@IP:/root/`), затем `cd /root/velo`.
5. `cp .env.example .env`, откройте `nano .env` и впишите токен, ID и домен (без https://).
6. `docker compose up -d --build`. Через минуту адрес https://ВАШ_ДОМЕН должен отвечать.
7. @BotFather: /mybots, ваш бот, Bot Settings, Menu Button, Configure menu button, укажите https://ВАШ_ДОМЕН. Откройте бота в Telegram и нажмите кнопку меню.

# Общий Caddy (важно)
С этого сервера оба приложения (выкуп и аренду) раздаёт один Caddy из `~/rent/proxy`, он занимает порты 80 и 443. В этом проекте своего Caddy нет, поэтому `docker-compose.yml` из этого архива менять на старый нельзя: иначе появится второй Caddy и контейнер не запустится с ошибкой «port is already allocated».

# Администраторы
Добавить администратора: «Настройки», «Администраторы», «Добавить». Нужны имя, телефон и галочки прав (принимать оплаты, досрочные платежи, штрафы и неустойка, клиенты, выкупы, велосипеды, отчёты). После сохранения приложение предлагает ссылку для входа: отправьте её администратору. Он открывает ссылку в Telegram и вводит свой номер телефона (должен совпасть с тем, что вы указали, сравниваются последние 10 цифр; 5 попыток в час). Telegram ID привязывается при первом входе.
Права «Выкупы», «Велосипеды» и «Отчёты» открывают закупочные цены, налог и прибыль; без них эти поля скрыты и не меняются. Права проверяет сервер, а не только приложение. Настройки, резервные копии, журнал и список администраторов видите только вы.
В карточке администратора: «Ссылка для входа» (новая ссылка), «Сбросить доступ» (привязка к Telegram снимается), «Отключить доступ» / «Включить доступ», «Удалить».
Если двое правят одну запись одновременно, второй видит «Эти данные только что изменились». Экран обновляется, чтобы сохранить правки первого пользователя.

# Уведомления в Telegram
Все сообщения бота по умолчанию выключены. Включаются в «Настройках», блок «Уведомления в Telegram»:
- «Сообщения вам»: сводка в 10:00 («Сегодня платят клиентов: N»), оплата или досрочный платёж, принятые администратором (сумма, период, остаток по графику), входы клиентов и администраторов, неудачные попытки входа. Оплаты, которые вы вносите сами, сообщением не дублируются.
- «Напоминания клиентам»: в 10:00 по Москве за день до платежа и в день платежа, один раз на каждый платёж (просроченным не отправляются). Клиент получает их, если открыл приложение по вашей ссылке.
Сводка и напоминания ставятся в очередь с 10:00 по Москве. Если сервер запустился позже, он отправит их в тот же день. После временной ошибки Telegram отправка повторяется. Успешная отправка регистрируется после ответа Telegram.

# Главная и «База»
На главной раскройте «План и факт по дням». Число просроченных стоит слева от заголовка «Просроченные платежи». В «Базе» показано количество велосипедов под выкупом и готовых к выдаче. Поиск в «Базе» проверяет все карточки, включая архив: ФИО, телефон, номер договора, название велосипеда и VIN. Разделы «Дисциплина клиентов» и «Велосипеды» в аналитике раскрываются по нажатию.

# Неустойка в сумме к оплате
При просрочке клиент на главном экране видит «К оплате сейчас»: просроченные платежи плюс неустойка на сегодня. Нажатие на сумму открывает детализацию («Платёж, период 5: 5 900 ₽», «Неустойка за 3 дня просрочки: 159 ₽», «Итого»). В графике у просроченных периодов сумма тоже с неустойкой. У вас та же сумма в списке «Просрочены» и в карточке выкупа, а на экране «Принять оплату» платёж и неустойка показаны отдельно и неустойка пересчитывается при смене даты получения денег.

# Должники и отмена неустойки по прежним договорам
**Частичная оплата.** На экране «Принять оплату» выберите оплату частями. Для прежних договоров минимальную долю можно задать в «Настройках» → «Платежи, штрафы и неустойка». Срок доплаты и правила начисления описаны в разделе «Версия 28».
**Долг.** Долг один на клиента: пока он не закрыт, «Часть» недоступна, платежи по графику принимаются только целиком. Долги видны на главной в блоке «Должники» (над «Просрочены»), в карточке выкупа («Принять оплату долга») и в отчётах. Долг можно внести целиком или частью (сначала неустойка, потом остаток). Последнюю оплату долга можно отменить, частичную оплату периода тоже, если по ней ещё нет оплат долга. Клиент видит остаток, срок и неустойку в приложении; напоминаний в Telegram по долгам нет.
**Управление начислениями.** В карточке выкупа откройте «Действия», чтобы списать начисленные штрафы и неустойку или приостановить и возобновить начисления. Эти действия доступны владельцу и администратору с правом «Штрафы и неустойка».

# Описания функций у клиента
На главном экране клиента рядом с «График платежей», «История оплат» и у карточки долга стоит значок «?». Нажатие открывает короткое объяснение простым языком; сама функция при этом не срабатывает. У платежа за период значка нет. Тексты лежат в `CI` в начале блока клиента (`static/index.html` собирается из исходников, правка текстов потребует новой сборки).

# Эквайринг, отчёты и чистая прибыль
Эквайринг (комиссия банка с платежей по СБП) задаётся в «Настройках», блок «Налог, эквайринг и неустойка», в процентах. По умолчанию 0: впишите ставку из договора с банком. Он учитывается как налог:
- при оформлении выкупа плановый расход считается от полной цены договора и вычитается из плановой прибыли.
- в «Отчётах»: ставка × деньги, фактически полученные по СБП за выбранный период (наличные и переводы не облагаются).
Период отчёта выбирается раскрывающимся списком вверху «Отчётов»: любой месяц (строго с 1 по последнее число), целый год или всё время. Рядом с каждым пунктом списка видна чистая прибыль. «Квартал» убран, блок «Налог по периодам» из «Аналитики» тоже: налог и эквайринг за выбранный период показаны в «Отчётах».
Окупаемость и прибыль считаются отдельно по каждому велосипеду. Поступления после налога и комиссий покрывают закупку, допы и обслуживание. Отчёты отдельно показывают обслуживание и ту часть новых поступлений, которая покрыла вложения. Допы при выдаче относятся к первому велосипеду. Исторические комиссии округляются до копеек по каждой операции и суммируются по видимым строкам.

# Списание и замена велосипеда
Списание: карточка велосипеда, «Списать» (причина, дата, сумма убытка; по умолчанию «вложено минус получено»). Велосипед уходит в архив, выкуп (если был) закрывается со статусом «списан», убыток попадает в «Отчёты». «Вернуть в парк» отменяет списание.
Замена: карточка выкупа, «Заменить велосипед». График и платежи не меняются, платежи до даты замены относятся к прежнему велосипеду, после неё к новому. Прежний велосипед возвращается в парк или сразу идёт на списание.

# Оплата по QR (Точка)
**Подключение.** «Настройки», блок «Оплата по QR (Точка)»: ID торговой точки (merchantId), ID счёта (accountId) в виде «номер счёта/БИК» через косую черту и JWT-токен из интернет-банка Точки. Нужно нажать «Подключить Точку». Пока эти три значения не введены, кнопок оплаты по QR у клиентов нет. «Отключить» убирает подключение и токен.
**Клиент.** Через «Выбрать оплату» можно получить QR за ближайшие взносы. Долг оплачивается отдельной кнопкой. В окне QR указано время окончания по Москве. Если срок близок к полуночи, новый расчёт можно запросить после 00:00.
**Вы и администратор с правом «Принимать оплаты».** Кнопка «Принять оплату» находится сверху карточки выкупа. «Действия» → «Оплата» содержит QR и выставление платежа. Другие разделы меню открывают график, данные клиента, велосипед и договор.
**Автоотметка.** Сервер спрашивает у Точки статус открытых QR: пока клиент смотрит на QR, не реже раза в 10 секунд, в остальное время раз в несколько минут, и сразу после вебхука. Если с момента создания QR ничего не изменилось (тот же день, та же сумма), оплата проставляется в выкуп сама, способ «СБП», вам приходит уведомление, если включены «Сообщения вам». Вебхук необязателен: адрес показан в настройках под кнопкой подключения, его можно вписать в Точке, чтобы оплата отмечалась быстрее.
**Не распознано.** В этом блоке видны подтверждённые платежи для ручного учёта и QR, которые нужно сверить с банковской выпиской. Если банк ещё не передал дату поступления, введите её из выписки. Перед зачислением приложение покажет неустойку на эту дату и остаток долга. Для QR вне окна автоматической проверки подтвердите операцию и её номер по выписке.
**Настройки банка.** При первом запуске v5 существующая настройка Точки переносится в защищённый файл `data/bank.json`. Новые JSON-выгрузки и SQLite-снимки содержат учётные данные выкупа без банковской настройки. SQLite-снимки старых версий могли сохранить банковский токен. При восстановлении JSON сервер использует текущее подключение банка. Переменные `TOCHKA_BASE` и `TOCHKA_MOCK` используются для тестов.

После изменения дат скачайте свежий файл. У просроченного взноса и остатка доступны сумма для расчёта неустойки, ставка, дата начала и число учтённых дней.

# Обращения об оплате и сверка СБП
В «Истории оплат» клиент нажимает «Я оплатил, но платёж не появился», вводит дату и сумму и при необходимости прикрепляет квитанцию PDF, JPG или PNG до 1,5 МБ. Вы видите обращение на главной и в карточке выкупа. После проверки можно отметить результат и написать ответ. Для учёта самого платежа используйте обычную оплату или сверку.

«База» или «Отчёты» → «Сверка СБП». CSV и XLSX до 2 МБ должны содержать дату и сумму поступления. Видны все входящие операции, включая строки без отметки СБП. Для QR точное совпадение учитывает номер операции, дату и сумму. Вручную можно связать банковскую строку с известной оплатой или принять точную фактическую сумму. Поступление сверх выбранных взносов покрывает будущие взносы с конца графика. Остаток сверх всего выкупа остаётся в разделе «Не распознано» до сверки.

# Возврат велосипеда и аналитика
В карточке выкупа через «Действия» оформите возврат велосипеда. Выкуп закроется, велосипед перейдёт в статус «На осмотре». В карточке велосипеда можно выбрать «В ремонте» или «Готов к выдаче». При оформлении или замене выкупа доступны велосипеды, готовые к выдаче. В карточке выкупа также можно закрепить служебную заметку для сотрудников.

В «Аналитике» прогноз показан по месяцам. Просрочка показана отдельной суммой. Отмечаются будущие платежи клиентов с минимум тремя учтёнными взносами, из которых хотя бы половина и не меньше двух внесены с опозданием. «Вложения в парк» показывает вложения и остаток до окупаемости отдельно для велосипедов под выкупом, на осмотре, в ремонте и готовых к выдаче.

# Копии, доступ, логи
Откройте «Настройки» → «Резервные копии» → «Скачать копию». Если в Telegram загрузка не открывается, выберите «Открыть в браузере». JSON до 128 МиБ можно загрузить через «Восстановить». Сервер проверит структуру и связанные записи до замены данных. Перед заменой он сохранит исходное состояние в `data/backups/pre-restore-….db`. Ночью в 03:00 по Москве создаётся новый снимок SQLite. Сервер хранит 30 ночных снимков.
Передать приложение другому человеку: `nano .env`, поменять OWNER_ID, `docker compose up -d`.
Логи: `docker compose logs app`.
Необязательные переменные `.env`: `PORT` (по умолчанию 8080), `DATA_DIR` (по умолчанию /data).


# Обновление v5
После загрузки файлов из архива в GitHub на сервере выполните команды из папки приложения.

```bash
cd ~/velo
git pull
docker compose up -d --build --remove-orphans
```

В настройках открывается нужный раздел. В архиве базы карточку клиента можно вернуть для повторного выкупа. Даты и записи предыдущих договоров сохраняются.

Графики и фактические банковские поступления, уже записанные в предыдущих версиях, сохраняются при обновлении. Если старую скидку нельзя восстановить по журналу, приложение покажет сообщение при попытке её отмены. В этом случае сверьте исходный график и банковскую выписку.
